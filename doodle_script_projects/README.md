# Doodle Script Projects

Dieser Ordner enthält neue Projekte für handgezeichnete 2D-Doodle-Erklärvideos.

## Fester Ablauf

1. Auswahl eines Themas aus fünf Vorschlägen oder Vorgabe eines neuen Themas.
2. Erstellung des vollständigen Sprecher-Skripts mit ungefähr 3000 Tokens.
3. Erst nach Fertigstellung des Skripts: Erstellung zeitcodierter Bildprompts.

## Stil der Bildprompts

- Hand-drawn 2D doodle cartoon animation
- Flat colors und kräftige schwarze Konturen
- Leicht unperfekte Markerlinien
- Klare, einfach lesbare Bildidee pro Szene
- Keine Verläufe, Schatten, Texturen, Fotorealistik oder 3D
- Seitenverhältnis 16:9
