Minecraft parkour background clips for Reddit Story Mode
========================================================

Put your OWN approved .mp4 parkour clips in THIS folder.

Reddit Story Mode picks one clip at random from here and plays it (looped, cropped to
1080x1920, original audio dropped) under the AI voiceover.

Rules:
- Only add clips you have the right to use. Do NOT scrape copyrighted parkour from
  YouTube / TikTok / Instagram etc. - the app will never do that for you.
- Supported: .mp4 (also .mov / .m4v / .webm).
- Longer clips are fine; short clips loop automatically to cover the narration.

If this folder is empty, generation fails cleanly with:
  "No approved Minecraft parkour clips found. Add .mp4 files to assets/parkour_pool/."

The .mp4 files here are gitignored (they are large binaries); only this README is tracked.
