Globale Shell

Ein einheitlicher Kopf auf jeder Seite: links die Marke, rechts die Navigation. Das ganze App läuft in einem eigenen nativen Windows-Fenster mit dem Pixel-Labor-Icon in der Taskleiste.

Kopfzeile & Navigation

  • Marke
    Shortslab-LogoPixel-Erlenmeyerkolben-Badge + Wortmarke „Shortslab“, links oben, klickt nicht.
  • Zurück
    Pfeil zurückNur im Timeline-Studio: dezenter Zurück-Pfeil ganz links (Browser-History bzw. → Assets).
  • Btn
    New projectStartet ein leeres Formular mit Standardwerten (verwirft die zuletzt geladene Sitzung). /?new=1
  • Btn
    AssetsÖffnet die Projekt-/Asset-Bibliothek. /assets
  • Tgl
    Theme-UmschalterSonne/Mond-Knopf: wechselt zwischen Dunkel- und Hell-Modus, wird gespeichert.
Atmosphäre
Glas-Panels, blauer Akzent, animierter blauer Hintergrund. Jeder Button spielt einen dezenten Klick-Sound; Hover- und Erscheinungs-Animationen (respektiert „reduzierte Bewegung“ nicht explizit — reine CSS-Deko).

Timeline-Studio

Der CapCut-artige Editor, verfügbar sobald ein Projekt seinen ersten Render hat. Spiegelt exakt den letzten Render (Captions + Sound + SFX) und erlaubt Trimmen, Mischen, Neu-Anordnen und Re-Rendern.

Werkzeugleiste

  • Btn
    💾 SaveSpeichert Timeline-Änderungen (markiert ungespeicherten Zustand).
  • Btn
    ⏬ RenderRendert die bearbeitete Timeline neu.
  • Tgl
    Render with captions · Sound FXZwei Render-Schalter: mit Untertiteln / mit Soundeffekten.
  • Btn
    🤖 Agent reworkDer Agent überarbeitet die Timeline.
  • Tgl
    Rework-Optionenreplace selected media · reorder & recut · regenerate speech + retime.
  • Btn
    📝 Change scriptÖffnet das Skript-Modal (siehe unten).
